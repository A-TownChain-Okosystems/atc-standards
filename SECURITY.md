# Security Policy — atc-standards

**Vulnerability Reporting:** Ueber GitHub Issues (security-Label) oder
direkt an den Owner. **Security Contact:** Michael Wroblewski (Owner).
**Supported Versions:** Nur der aktuelle main-Stand.
**Disclosure Policy:** Keine oeffentlichen Exploit-Details vor Fix.
**Security Scope:** Normative Regeln; Verstoesser gegen ATC-STD-REPO-003
(Secrets, unsichere Releases) werden als Governance-Verstoss behandelt.
**Known Limitations:** Markdown-Standards sind referenziell, nicht
maschinell erzwungen — Durchsetzung liegt in den Repositories/CI-Gates.
