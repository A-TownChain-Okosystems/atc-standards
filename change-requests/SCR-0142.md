# SCR-0142 — Machine-Readable SCR Registry and Identity Validation

## Affected Standard
ATC-STD-000 §§14 and 20 are the procedural basis. This proposal does not amend ATC-STD-000 or another approved standard.

## Proposed Change
- Add registry/scr-registry.yaml as the SCR identity and allocation SSOT.
- Add schemas/scr-registry.schema.json.
- Add a fail-closed validator for uniqueness, file references, repository coverage and unresolved-range overlap.
- Add a dedicated CI gate and positive/negative tests.
- Reconstruct historical identifiers only from commit, PR, issue and Owner evidence.
- Keep the standard-ID allocation registry and validator separate.

## Motivation
CHANGE_CONTROL.md contains only a four-row manual registry. P1-A6 records SCR-0093 through SCR-0115 tracking fragmentation. PR #116 reserves SCR-0140 as an open Draft. SCR-0141 is present but explicitly provisional. Absence of a file is not evidence that an identifier is available.

## Compatibility Impact
No changes to ATC-STD-000, ATC-STD-202, ATC-ARCH-001, ATC-STD-204, standard-ID allocation, product implementations, interfaces, dependency edges or generated views. The SCR gate is additive.

## Security Impact
The validator uses local repository evidence only. It performs no network access, credential access, execution of registry-supplied code or automatic ID assignment. Invalid or contradictory evidence fails closed.

## Migration Impact
The initial inventory distinguishes file-present identifiers, PR reservations, provisional identities and unresolved historical ranges. File presence alone does not establish Owner approval, implementation or closure.

## Decision
PENDING — Owner decision and required governance reviews are not recorded. Draft PR presence does not imply approval or permission to merge.

## Acceptance Criteria
- All canonical SCR filenames are covered by an explicit entry or blocked unresolved range.
- Duplicate IDs, overlaps and missing referenced files fail validation.
- Unknown or missing identities are never classified as FREE.
- SCR-0140 remains reserved by PR #116; SCR-0141 remains provisional.
- Positive and negative tests pass.
- Existing standards and product implementations remain unchanged.
